SDK-PDK Redux

Downloading and Installing webOS SDK and PDK

This document describes efforts to restore and update the webOS SDK and PDK originally created by Palm, and updated by HP for the mobile (phone and tablet) webOS.
These efforts expand the scope of the toolset to webOS descendants like webOS CE, LuneOS (Open webOS), and Lunacy, while maintaining support for the legacy devices on newer development platforms.

The updated SDK tools, call the "SDK Redux" are available on GitHub: github.com/webOSArchive/webos-sdk-redux
The original HP webOS 3.0.5 SDK documents, which had been patched and modified to keep things functional, are available here for historical purposes, but are no longer maintained, and in most cases, should not be used.

You can install the SDK on Windows, mac OS, and Ubuntu Linux host PCs. For C/C++ development, the PDK contains toolchains that can be used on Linux environments.

Note: PDK development is now supported for Linux. See the Linux download section below for more information.

The SDK tools are also command-line based, but if you prefer to use an integrated development environment (IDE) there are some options:

  • HP provided a webOS plug-in for the Eclipse IDE (no longer maintained).
  • Hobby developer codepoet has developed VisualStudio Code extensions for webOS.

Installing the SDK and PDK on a Windows PC

  1. Uninstall any previous SDK (if present) using the Windows Add/Remove Programs control panel.
    • If prompted, make sure you also un-install the Novacom driver.

Install Java 8

Download and install the latest version of Java™8.
To verify that Java is installed, go to the Command Prompt and type:

java -version

If Java is installed, Java version information appears.

Download Java

Note:

On legacy systems, the Windows installer does a Java version check, so you must use a version it recognizes for the install. For a modern system, use any recent version of Java JRE.

Install Drivers

The legacy Novacom drivers for both 32-bit and 64-bit Windows (7-11) are still usable.

Windows Devices Drivers

Install the SDK

On legacy Windows 7 or 32-bit systems, download and run the original SDK installer:

SDK for Windows 32-bit

On macOS 11 and higher, download the latest SDK Redux release Zip from GitHub:

Modernized SDK Releases

Extract the Source code zip.

Open a Terminal window and change directory to the unzipped folder, then run:

./install.sh

Follow the prompts to install any missing dependencies (standard build tools and libusb). If you receive a warning about installing along-side a previous version of the SDK, press Y to accept (this is usually due to the previous driver installation)

Note that the installer will re-install the drivers, but this step is harmless if you've already installed them.

Once the SDK is installed the webOS command-line tools become available from the Terminal.

If you have issues with the install, see Windows documentation on GitHub.d

Installing the SDK on Linux

Note: Palm/HP only supported Ubuntu-based Linux, and the modernized installer script still expects it -- largely for the systemd requirement.
The drivers and tools will work on other distros, but you'll need a service unit, cron job, or some other mechanism to get novacomd running persistently. The installer script will only set this up if systemd is present.
If you can help expand the installer to your preferred distro, please send a PR here!

Update your Package Repository Information

sudo apt-get update
or 
dnf check-update

Install Java

sudo apt install default-jre
or 
sudo dnf install java-latest-openjdk

Install ia32-libs (on 64-bit systems only)

If you are installing on a 64-bit system, perform the following additional step before installation:

sudo apt-get install ia32-libs

Note: On newer Linux distros, this Stack Overflow answer provides working instructions if the above does not work. You may also need to install libc6-i386: 

sudo apt-get install libc6-i386

Install Drivers and SDK (legacy instructions)

Note: If the Modernized Install steps above do not work for you, these original install steps, updated with notes and work-arounds, may help. If the Modernized Install was successful, you do not need to do these steps...

A note about PDK development on Linux: The current SDK for Linux includes headers and libraries needed to do PDK development for the device and for the emulator. It also includes an arm-gcc toolchain for compiling applications for the device. If you are running a 32-bit i686 Linux desktop, you should be able to use the standard g++ compiler. (On x64 Linux, the native desktop toolchain will generate x64 code, which will not work in the emulator.)

These instructions were originally written for Ubuntu 14.04.5 LTS (Trusty Tahr), notes have been added where the installation process differs for more modern releases, and have been tested on Ubuntu 20.04 LTS.

Install Java™ 8

Follow these instructions: install Oracle Java 8.

Download and install the OpenJRE Java Runtime Environment (JRE). The SDK is incompatible with the default Ubuntu GNU Compiler for Java (GCJ), and the Java JRE is no longer available. Example:

sudo apt-get install openjdk-8-jre

To set Oracle JDK8 as default, install the "oracle-java8-set-default" package. 

sudo apt install oracle-java8-set-default
On Ubuntu systems, oracle-java8-set-default is most probably installed automatically with this package.

Install Drivers

Note: On modern Linux you will need to install pre-requisites for both 64-bit and 32-bit architectures: 

sudo apt install libusb-0.1-4
sudo apt install libusb-0.1-4:i386

The Novacom drivers are available for supported Linux platforms.

Download Drivers

Note: On modern Linux you will get an error after installing novacom. Community member Herrie describes how to setup a systemd service unit...

Paste the following into the file: /etc/systemd/system/palm-novacomd.service
[Unit]
Description=Palm NovaCom, Palm's debug/control protocol server.

[Service]
#Environment=
WorkingDirectory=/opt/Palm/novacom/
ExecStart=/opt/Palm/novacom/novacomd
Restart=always

[Install]
WantedBy=multi-user.target

Then, from the command line execute:

sudo chmod 733 /etc/systemd/system/palm-novacomd.service

Next, reload the service daemon:

sudo systemctl daemon-reload

Now you can start the service with:

sudo service palm-novacomd start

Finally, call this command to auto-start the service on boot:

sudo systemctl enable palm-novacomd.service

Install the SDK

Download SDK

If you are installing on a 32-bit system, perform the following steps to install the SDK: 

sudo dpkg -i palm-sdk_3.0.5-svn528736-pho676_i386.deb
sudo dpkg -i palm-novacom_1.0.76_i386.deb

If you are installing on a 64-bit system, perform the following steps to install the SDK:

sudo dpkg -i --force-architecture palm-sdk_3.0.5-svn528736-pho676_i386.deb
sudo dpkg -i --force-architecture palm-novacom_1.0.76_amd64.deb

AI Assisted Development

Modern AI development tools actually work great for webOS development -- with a few caveats. AI needs to be reminded to target ES5-only features (for SDK apps) and note the old GCC version (for PDK apps).

A pre-made MCP server that provides critical knowledge to an AI coding agent can be found on NPM and Github. Even if you prefer to code more artisanally, the knowledge folder can help you learn the quirks and avoid common potholes.

Once you have downloaded the zip file, you will need to "install" the image using the palm-emulator command from the command line. For example:

palm-emulator --install "~/Downloads/SDK 2.1.0.519.vmdk.zip"

Keyboard Shortcuts

You can simulate some hardware events and states with keyboard shortcuts:

  • End (use Fn+Right Arrow on a Mac): Opens and closes the launcher
  • Esc: Performs the back gesture (or swipe back)
  • Home (use Fn+Left Arrow on a Mac): Minimizes and maximizes the card
  • Left/Right Arrow: Switches the application left or right in the Card view
  • F5: Simulate shaking (Not implemented)
  • F6: Simulate "up" (12:00 or normal) orientation
  • F7: Simulate "down" (6:00) orientation
  • F8: Simulate "right" (3:00) orientation
  • F9: Simulate "left" (9:00) orientation

Screen-size Notes

SDK Apps (Mojo and Enyo)

  • Pre3: To avoid the letterbox bar that will show on the Pre3 if your app retains it's Pre/Pre2-based aspect ratio, add the following to your index.html: 
    <meta name='viewport' content='height=device-height'>
  • TouchPad: To avoid the phone simulator frame that will show on the TouchPad if your app retains it's Pre/Pre2-based aspect ratio, add the following to your appinfo.json: 
    "uiRevision": "2",

PDK Apps (C and C++)

  • To allow the screen content to resize on different devices, include a file named metadata.json in the root of your application's directory, with the following content: 
    {"version":1,"devices":[101]}

Note: This file can be added to applications already installed on a device to improve compatibility. Copy the file to /media/cryptofs/apps/usr/palm/applications/<pdk-app-folder>
A reboot will be required for the change to take effect.

Install Locations

One of the easiest ways to learn about developing SDK apps is to examine other SDK apps that are installed on your device.
Using a tool like Internalz Pro, you can navigate to the install location, and copy the deployed App folder to a location accessible from USB Disk Mode (such as /media/internal/).
Here are some common install locations:

  • webOS Pre-Installed Apps: 
    /usr/palm/ipkgs/
  • webOS System Apps: 
    /usr/palm/applications/
  • User Installed Apps: 
     /media/cryptofs/apps/usr/palm/applications/

Warning:

Use caution when working with files within the cryptofs folder. This folder is designed to be secured by the operating system and should usually be considered read only. Copy contents out before you make any edits.
